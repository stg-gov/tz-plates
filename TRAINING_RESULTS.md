# Training results — 30 August 2026

First GPU run of the CRNN+CTC OCR model on the Tanzanian labelled stills.
Hardware: **NVIDIA GeForce RTX 5090**, PyTorch `2.11.0+cu128`.
Recipe: `bash scripts/gpu_train.sh` (audit → crop → synthetic → overfit check →
pretrain → fine-tune → evaluate → calibrate).

Weights written locally (git-ignored except the small open plate detector):

| File | Role |
|---|---|
| `models/ocr/v1/ocr_crnn.pt` | runtime OCR (best fine-tune, epoch 75) |
| `models/ocr/v1/ocr_pretrained.pt` | synthetic-only stage 1 |
| `models/ocr/v1/confidence_calibration.json` | Platt `a=1.200`, `b=-1.549` |
| `checkpoints/ocr-finetune-75-0.8984.ckpt` | Lightning checkpoint (`val/char_acc` 0.8984) |
| `models/plate_detector/v1/plate_yolo.pt` | HF YOLOv11-nano plate detector (bootstrap) |

ONNX export was not produced (`torch.onnx.export` required `onnxscript`). Serve
with `TZ_ALPR_RUNTIME=torch`.

## Against spec §33

| Target | This run |
|---|---|
| End-to-end exact-match ≥ 95% daytime | **73.4%** day / **73.8%** overall test — not yet |
| Separate hard / night / motorcycle numbers | reported above |
| GPU latency < 100 ms/image | ~850 ms end-to-end on first images (detector + OCR, unoptimized); OCR itself is a few ms |

Largest gaps: weak plate boxes on two-line Tanzanian plates, motorcycle / tiny
crops, and residual E/H and dropped-character errors. Next levers: hand-verify
YOLO boxes and train a project plate detector; more real two-line crops in
fine-tune; keep the review band for anything under 0.90.

Spot check (notebook `notebooks/test_model.ipynb`, 12 random labelled photos,
seed 7): **8 / 12** exact, including a correct `T336CAG` read at confidence 0.88.

`python tools/analyze_dataset.py` or `bash scripts/retrain.sh`).
